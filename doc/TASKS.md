## 第 1 层｜LLM 应用基础

### 1.1 统一 ChatClient `[x]` ✅ 2026-11-21

- [x] YAML 配置 + `${ENV}` 占位符

**验收**：改 `llm.default` → 重启 → 模型切换成功，代码未动。
**状态**：已验收（deepseek ⇄ qwen 双向验证）

### 1.2 参数控制 `[x]` ✅ 2026-11-22

- [x] `temperature`（0~2）
- [x] `max_tokens`（含厂商级默认值）
- [x] `top_p`（核采样）
- [x] `stop`（停止序列）
- [x] 能解释「同一 prompt 两次结果不同」的原因，并调稳定

**验收**：能说出 `temperature` 和 `top_p` 的区别，以及什么场景只调其中一个。

| 参数 | 控制什么 | 怎么用 |
|---|---|---|
| `temperature` | 概率分布的**陡峭程度** | 抽取/分类用 0~0.3；创作发散用 0.8~1.2 |
| `top_p` | 只从累积概率前 P 的词里选（**截断尾巴**） | 0.9 表示丢掉最不可能的 10% |
| `stop` | 遇到指定字符串就停 | 截断多余的"以上。"/分隔线 |

**关键区别**：`temperature` 低会让模型变"死板"（总是选最高概率词），
`top_p` 低会直接**禁止**低概率词。两者都调低会过度保守。
**一般只调一个**，另一个保持默认 —— 同时调低容易让输出变得机械重复。

### 1.3 结构化输出 `[x]` ✅ 2026-11-21

- [x] `response_format: json_object` 支持
- [x] `response_format: json_schema`（严格模式，按厂商能力降级）
- [x] 解析容错：去掉 ` ```json ` 围栏、前后废话
- [x] 解析失败自动重试一次（带错误信息 + 完整 schema 回灌）
- [x] 用 Jackson 反序列化成 record
- [x] 至少一条业务校验（字段非空 / 枚举合法）
- [x] schema 同时写进提示词（应对「厂商接受参数但不执行」）

**验收**：同一段自然语言 → 稳定输出可反序列化的对象（实测 2.2s 抽取成功）。
**关键教训**：DeepSeek 接受 `json_schema` 但**不强制执行枚举约束**，模型返回了中文 `"中"` 而非 `MEDIUM`。只靠 `response_format` 不够，**提示词里必须再写一遍 schema**。

### 1.4 Function Calling `[x]` ✅ 2026-11-22

- [x] 工具定义（name / description / parameters schema）
- [x] `tools` 参数传入 + `tool_calls` 解析
- [x] 工具执行 + 结果回填（`role: tool` + `tool_call_id`）+ 二次请求
- [x] 多工具串行调用（查设备 → 算差值，3 轮收敛）
- [x] 工具不存在 / 参数非法 / 执行抛异常时的兜底（都转成错误 JSON 回填）
- [x] `maxSteps` 死循环防护

**验收**：模型自己决定「先查设备再算差值」，3 轮收敛，实测 2576 ms / 1805 tokens。
**关键设计**：`ToolRegistry.execute()` **永远不抛异常**——失败也返回 `{"ok":false,"error":...}`，
让模型看到错误自己决定下一步，而不是让整个对话崩掉。

## 技术债 / 待补

| 项 | 来源 | 优先级 |
|---|---|---|
| 自动重试循环 | 1.6 只做了判定 | 中 |
| **章节归属漂移** | 部分标题被合并进正文，`isHeading` 认不出，导致 chunk 章节标错 | **高** |
| **纯向量检索的盲区** | 精确词（E0012、M12×25）命中差 | **高**（2.6 解决） |
| **排序错位** | 词汇重叠但答非所问的段落排在正确答案前 | **高**（2.7 解决） |
| 无相似度阈值 | 现在靠 prompt 拒答，不是靠分数 | 中（2.8 解决） |
| PgVectorStore 单连接 | 非线程安全，`ask()` 用 synchronized 兜底 | 中 |
| 智谱 / Kimi 实测 | 只有配置没有 key | 低 |
| 会话状态持久化 | 现在每次都是新对话 | 低 |
| Token 估算精度 | 现在按字数粗算 | 低 |
